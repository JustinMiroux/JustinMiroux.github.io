Mission 2 - Le badge SSH de Bob


Partie 1

Dans le fichier "/etc/pam.d/sshd" décommenté la ligne suivante :

# account    required    pam_access.so

Et dans le fichier "/etc/security/access.conf" ajouté a la fin la ligne suivante :

-:bob:ALL


Partie 2

Dans le fichier "/etc/pam.d/sshd" commenté la ligne suivante :

account    required    pam_access.so

Puis (toujours dans le même fichier) ajouté la ligne suivante :

auth    required    pam_succeed_if.so user ingroup sshusers

Pour finir, créer le groupe "sshusers" et ajouté y votre utilisateur :

addgroup sshusers
usermod -aG sshusers YOUR_USER
